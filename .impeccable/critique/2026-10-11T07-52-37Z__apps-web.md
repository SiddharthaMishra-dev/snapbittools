## Design Specificity Verdict

**LLM assessment:** Mostly interchangeable. The live shell is a generic file utility: glassy top bar, category links, gray sidebar, dashed cloud dropzone, one blue button, dual-pane editor. Privacy is a sentence and a lock icon ("Processed in your browser. Nothing is uploaded to a server."), not a visual system. Home, the compressor, and the JSON formatter could move to another file-utility brand without a structural change.

## What's Working

- Compressor empty state: "Compress Images", the dashed "Upload images" target, one blue "Select Images", and "Processed in your browser. Nothing is uploaded to a server."
- Location is obvious. "Image Compressor" and "JSON Formatter" sit in a sidebar pill, with "Close sidebar" available.
- Empty JSON refuses dead actions. Format, Minify, Copy, Download CSV, and Clear stay disabled until Input has text. "Search tools (Ctrl K)" is visible in the header.

## Priority Issues

### [P1] The tool is the top of a landing page
- **Why it matters:** Under Select Images the page becomes Key Benefits, Common Use Cases, Frequently Asked Questions, Also useful for (Compress Image to 50KB, Compress PNG Online), and Other Image tools. The person came to compress a file and lands in keyword cards. The same pattern sits under the JSON editor.
- **Fix:** End the tool visually after the result. Move benefits, use cases, and variant links below that end, or onto a separate read page.
- **Suggested command:** /impeccable distill

### [P1] Two catalogs, and the wrong one follows you
- **Why it matters:** The header repeats Images, PDF, Data, Utility, All, and Blogs while the sidebar lists every tool. On JSON Formatter the sidebar Blogs block is image-compression posts. Home offers Browse all tools, View all SnapBit Tools, See all tools, and Go to all tools for one destination.
- **Fix:** Keep the header to the logo, search, and theme. Keep the sidebar as the catalog. Show blogs about the tool that is open, or take blogs off tool pages.
- **Suggested command:** /impeccable distill

### [P1] The JSON action bar is a wall
- **Why it matters:** In this viewport the first row is ", ', Format, Minify, Copy, and Download CSV. The next row is Clear and Fullscreen, all the same weight, above Input and Output. Formatted and Minified then repeat Format and Minify. Download CSV belongs on JSON to CSV.
- **Fix:** Let the textarea lead. Keep Copy as the primary action. Put quote style, CSV export, and fullscreen in one menu.
- **Suggested command:** /impeccable distill

### [P1] Compression runs before the person can aim it
- **Why it matters:** Files auto-compress before Preserve original format and Quality (Smaller file / Higher quality) can be set. Key Benefits still promises dimension controls that are commented out of the tool. The finished row's download is a green icon. Clear All is red text with no confirm. The zip "ZIPPING..." state never turns on because the flag is only cleared, never set.
- **Fix:** Show quality before the run, add a Compress action, label the per-file button Download, and show original size, new size, and ratio. Add per-file remove.
- **Suggested command:** /impeccable harden

### [P2] Gray text fails contrast, and errors stop at the alert
- **Why it matters:** The live scan measured `#9ca3af` on white at 2.5:1, under the 4.5:1 text floor, plus a 10px NEW badge and a JSON placeholder at 3.4:1. A bad file uses a browser alert. Invalid JSON shows the parser string without the line numbers the FAQ describes.
- **Fix:** Raise muted text and the NEW badge to readable sizes and contrast. Put the error on the dropzone or under Input, and point at the line.
- **Suggested command:** /impeccable audit

## Persona Red Flags

**Alex (power user):** Ctrl K is the only accelerator. Quality cannot be set before the first pass, so there is no A/B against the previous size. The per-file control is an unlabeled green download icon next to ZIP. Clear All cannot be undone. Format, Minify, and Copy have no keys. Image-compression blog posts sit in the sidebar on JSON Formatter.

**Jordan (first-timer):** Select Images is obvious. The " and ' buttons and Download CSV on a formatter are not. CSV ↔ XLSX is a symbol. After a successful compress, success is a green size chip and an icon, with no word Download. Home's four "all tools" links do not say which one is the door.

**Casey (mobile):** Phone width was not opened. From the layout: category words drop below the md breakpoint and become icons. All and Blogs hide below lg. The logo words hide below sm. The dropzone uses large padding, so Select Images sits far down a short screen. JSON actions wrap into a tall stack, and Input stacks over a full-height Output.
